## 概要

法 $998244353$ 上のNumber Theoretic Transform（NTT）と畳み込みを提供する。
`modint998`のMontgomery表現を直接扱い、x86環境ではAVX2を利用する。

C++20以降が必要。

## 基本的な使い方

```cpp
#include <iostream>
#include <vector>

#include "convolution/ntt998.hpp"

int main() {
    using mint = eez::ntt998::mint;

    std::vector<mint> a = {1, 2, 3};
    std::vector<mint> b = {4, 5};
    const auto c = eez::ntt998::convolution(a, b);

    for (const mint value : c) {
        std::cout << value << ' ';
    }
}
```

## 畳み込み

```cpp
std::vector<mint> convolution(
    std::span<const mint> a,
    std::span<const mint> b);

std::vector<mint> square(std::span<const mint> a);
```

- 返り値の長さは、空でない入力に対して `a.size() + b.size() - 1`
- どちらかが空なら空のvectorを返す
- `square(a)`は同じ列同士の畳み込み専用
- 短い入力では愚直法、それ以外ではNTTを使う
- 畳み込みの変換長は最大 $2^{25}$

畳み込みでは末尾4点を愚直計算するため、通常のNTTより大きい変換長を扱える。

計算量は $O((N+M)\log(N+M))$、追加メモリは $O(N+M)$。

## メモリの再利用

```cpp
eez::ntt998::workspace ws;
std::vector<mint> out(a.size() + b.size() - 1);

eez::ntt998::convolution_to(a, b, out, ws);
eez::ntt998::square_to(a, out, ws);
```

`workspace`を使うと、複数回の畳み込みで作業領域を再利用できる。
`out`は結果を格納できる長さを確保しておく必要がある。

## Large向けin-place API

```cpp
const std::size_t size =
    eez::ntt998::convolution_transform_size(n, m);
eez::ntt998::convolution_buffer a(size), b(size);

// a[0..n), b[0..m) に入力する。残りは0で初期化済み。
eez::ntt998::convolution_inplace(a, b);
```

`convolution_buffer`は64バイト境界に整列した固定長バッファで、長さは32以上 $2^{25}$ 以下の2冪にする。
計算結果は`a`に入り、`b`の内容は不定になる。入力vectorと出力vectorを別に保持しないため、巨大な入力でメモリ使用量を抑えられる。

## NTT

```cpp
eez::ntt998::forward(values);
eez::ntt998::inverse(values);
```

`values.size()`は1以上 $2^{23}$ 以下の2冪でなければならない。
`inverse`は逆変換と同時に要素数の逆数で正規化する。

## 周波数領域を再利用するAPI

```cpp
eez::ntt998::frequency_buffer fa, fb;
const std::size_t size = eez::ntt998::transform_size(a.size(), b.size());

eez::ntt998::forward_to(a, fa, size);
eez::ntt998::forward_to(b, fb, size);
eez::ntt998::pointwise_multiply(fa, fb);
eez::ntt998::inverse_to(fa, out);
```

`pointwise_square(fa)`も使用できる。

## 補助関数と定数

```cpp
eez::ntt998::mod;              // 998244353
eez::ntt998::max_ntt_size;     // 2^23
eez::ntt998::max_convolution_size; // 2^25
eez::ntt998::max_size;         // 2^23（互換用）
eez::ntt998::naive_cutoff;     // 60

eez::ntt998::convolution_size(n, m);
eez::ntt998::transform_size(n, m);
eez::ntt998::convolution_transform_size(n, m);
eez::ntt998::valid_ntt_size(n);
eez::ntt998::valid_convolution_transform_size(n);
```

`transform_size(n, m)`は通常NTT用、`convolution_transform_size(n, m)`は畳み込み用の変換長を返す。各上限を超える場合は0を返す。

## 注意

- x86向けビルドではAVX2、BMI/BMI2、LZCNT、POPCNT命令を使用する
- $2^{25}$ の畳み込み上限を超える場合は`std::length_error`
- 不正な変換長や短すぎる出力spanは`std::invalid_argument`
